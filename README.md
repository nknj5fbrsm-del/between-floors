# Between Floors

Album-Dokumentation: Score (LilyPond) → Sound (Suno) → Bigband.

**Online:** nach dem Deploy unter  
`https://nknj5fbrsm-del.github.io/between-floors/`

Workflow-Skill (im Projekt): `@score-sound` — Menü für Neu (bis MP3) bzw. Fertig (PDF + GitHub Pages).

Lokal hören:

```bash
cd docs/album && python3 -m http.server 8080
# → http://localhost:8080/between-floors-album.html
```
